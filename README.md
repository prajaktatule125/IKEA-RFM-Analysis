# E-commerce Customer Analytics & RFM Segmentation

**Tools:** SQL Server | Python | Pandas | Power BI | DAX

## Project Overview

This project focuses on analyzing customer purchasing behaviour, identifying valuable customer segments, and understanding customer churn patterns using two years of retail transaction data.

The objective is to help the business understand which customers contribute most to revenue, identify customers at risk of disengagement, and support data-driven customer retention strategies.

## Business Objectives

- Identify high-value customers using RFM segmentation.
- Analyze customer purchasing behaviour and revenue contribution.
- Identify churned customers using a fixed 90-day inactivity threshold.
- Evaluate customer retention and performance across different countries.
- Provide actionable recommendations for each customer segment.

## Dataset

**Source:** [Online Retail II – UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

- Contains approximately 1.07 million transaction records.
- Covers two periods: December 2009–December 2010 and December 2010–December 2011.
- Includes invoice details, product information, quantities, unit prices, customer IDs, and countries.

## Project Workflow

### 1. SQL Server – Data Cleaning & Exploratory Data Analysis

- Combined two yearly datasets using `UNION ALL`.
- Standardized InvoiceDate and Price data types using `TRY_CONVERT()` and `COALESCE()`.
- Checked missing Customer IDs and failed data type conversions.
- Investigated negative quantities and potential data quality issues.
- Identified exact duplicate transaction records using `GROUP BY` and `HAVING`.
- Removed exact duplicates using `ROW_NUMBER()` and created a cleaned dataset.

### 2. Python – Customer Analytics & RFM Segmentation

Used Python and Pandas to perform customer-level analysis.

**RFM Analysis:**

- **Recency:** Days since the customer's most recent purchase.
- **Frequency:** Number of distinct purchase transactions.
- **Monetary:** Total revenue generated by the customer.

Customers were scored based on their purchasing behaviour and classified into six segments:

| Segment | Description |
|---|---|
| Champions | Highest-value and most engaged customers |
| Loyal | Consistent customers with repeat purchases |
| At Risk | Previously valuable customers with declining recency |
| New | Recently acquired customers |
| Needs Attention | Customers requiring engagement |
| Lost | Customers inactive for an extended period |

**Churn Analysis:** Applied a fixed 90-day inactivity threshold to identify churned customers.

### 3. Power BI – Interactive Dashboard

Developed a multi-page interactive dashboard using Power BI and DAX.

**Page 1 – Home**
- Project introduction and navigation.

**Page 2 – Business Overview**
- Total Customers, Total Revenue, Churn Rate, and Average Customer Value.
- Revenue contribution by customer segment.
- Customer distribution by segment and churn status.
- Monthly, quarterly, and yearly customer and revenue trends.

**Page 3 – RFM Analysis**
- Segment Performance Summary with customer counts, revenue, and average RFM scores.
- Churned customer counts and churn percentages by segment.
- Country Performance Summary with customer value and churn metrics.
- Average Customer Value comparison across segments and countries.
- Churn trends by last purchase period.
- Segment-specific business recommendations.

## Key Business Questions

1. Which customer segments contribute the most revenue?
2. How are customers distributed across the six RFM segments?
3. Which segments have the highest churn rates?
4. How does customer value and churn risk vary across countries?
5. What retention strategies should be considered for different customer segments?

## Recommended Business Actions

| Segment | Recommended Strategy |
|---|---|
| Champions | VIP rewards and exclusive benefits |
| Loyal | Loyalty incentives and cross-selling |
| At Risk | Targeted win-back campaigns |
| New | Welcome offers and second-purchase incentives |
| Needs Attention | Purchase reminders and personalised offers |
| Lost | Low-cost reactivation campaigns |
